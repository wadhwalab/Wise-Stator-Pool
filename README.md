# Regulation of flagellar motor mechanosensitivity by stator pool size

This repository contains the manuscript, processed data, analysis code, and manuscript-ready figure PDFs for a study of how the cellular stator pool affects bacterial flagellar motor output and mechanosensitivity in *E. coli*.

## Repository layout

| Path | Contents |
|---|---|
| `manuscript/main.tex`, `manuscript/main.bib` | LaTeX manuscript source and bibliography |
| `manuscript/Figures/` | Manuscript-ready figure PDFs used by `main.tex` |
| `stator-pool-figures/` | Source figure assets and editable figure files |
| `code/` | Python scripts and notebooks for simulations, swimming-cell analysis, tethered-cell analysis, and mechanosensing plots |
| `figure-output/` | Plots generated by Jupyter Notebooks |
| `swimming-cells/` | Processed swimming-speed CSVs and swimming data documentation |
| `tethered-cells/` | Processed tethered-cell rotation results and tethered-cell data documentation |
| `REPRODUCING.md` | Practical guide to reproducing the main analyses and outputs |
| `requirements.txt` | Python package list for the analysis environment |

## Quick setup

Install the Python dependencies from the repository root:

```bash
pip install -r requirements.txt
```

The Python scripts and notebooks use NumPy, pandas, matplotlib, SciPy, OpenCV, pims, scikit-image, circle-fit, and Jupyter. Fiji/ImageJ with TrackMate is needed only for the video-tracking script `code/Swimming-Tracks.py`; the processed swimming CSVs needed for the notebook analyses are already included.
